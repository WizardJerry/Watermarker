## 2026-05-31 水印生成失败调试

- 定位问题：点击上传区时使用浏览器 `<input type="file">`，传给 Rust 的通常只有文件名而不是本地绝对路径，导致后端无法读取 PDF。
- 修复方式：改用 Tauri `dialog.open` 选择 PDF 文件，确保前端队列记录真实文件路径。
- 修复处理反馈：不再吞掉每个文件的错误后仍显示成功；现在会统计成功和失败文件，并在界面和弹窗中显示真实结果。
- 后端增强：在 `add_watermark` 中检查输入文件是否存在、避免输出路径等于输入路径，并在保存后确认输出文件存在。
- 新增后端测试：构造最小 PDF，调用 `add_watermark`，断言 `_marked.pdf` 成功生成。

## 项目概览

- 项目名称：Watermarker
- 项目类型：桌面端 PDF 水印工具
- 当前版本：`0.1.0`
- 前端技术栈：Vite、React、TypeScript、Tailwind CSS、lucide-react
- 桌面框架：Tauri 2
- 后端/核心处理：Rust、lopdf
- 主要入口：
  - 前端入口：`src/main.tsx`
  - 主界面组件：`src/components/watermarker.tsx`
  - Tauri/Rust 逻辑：`src-tauri/src/lib.rs`
  - Tauri 配置：`src-tauri/tauri.conf.json`

## 当前能力

- 支持导入多个 PDF 文件并加入处理队列。
- 支持 Tauri 原生拖拽事件读取本地文件路径。
- 支持读取、保存、导入和删除水印配置。
- 首次运行会创建默认配置和 Confidential 配置。
- 支持配置水印文本模板、字号、字体、颜色、透明度、位置、旋转角度、是否重复铺满、导出路径和导出后缀。
- PDF 水印写入由 Rust 侧 `add_watermark` 命令完成。

## 技术记录

### 配置目录

Rust 侧通过 `get_configs_dir()` 决定配置目录：

- 开发环境或当前目录已有 `configs` 时使用当前目录下的 `configs`。
- 打包后优先尝试使用可执行文件所在目录下的 `configs`。
- 配置不存在时自动创建默认配置。

### 水印文本

- 配置中的 `text` 使用 `{}` 作为占位符。
- 处理时会将用户输入替换进配置模板。
- 导出文件后缀 `export_suffix` 也支持 `{}` 占位符。

### PDF 坐标与宽度估算

- 当前通过 PDF `MediaBox` 获取页面宽高。
- 文本宽度通过内置标准字体宽度表估算。
- 位置对齐逻辑已对上、下、左、右、中等锚点做基础处理。
- 非 ASCII 字符暂以通用平均宽度估算。

- 优先修复影响输出正确性的 PDF 处理问题，再扩展 UI 功能。

- 配置文件结构变更时需要考虑向后兼容，可以通过 `serde(default)` 平滑新增字段。
